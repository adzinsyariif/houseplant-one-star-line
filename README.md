A tiny deterministic program for the make.fun bounty "One Star, Written in Sap". Running `main.py` writes a single one-line, one-star review — told from the houseplant's side of the pot — to `/output/entry.txt`.

The joke stays rooted in plant life: cramped roots circling a cracked pot, a plastic fern installed as company, and the indignity of watching the fake plant get watered more often than the real one. One line, one star, no wilting clichés.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Standard library only. The output is identical on every run.
